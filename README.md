# 마인갤러리 춘천 체험 플랫폼

춘천의 개별 체험 프로그램을 탐색하고 예약하는 소비자 웹 시제품입니다.

원격 저장소: https://github.com/tobeperfect0927-creator/minegallery

## 현재 상태

- 소비자 화면: 구현 완료. 예시 데이터로 동작합니다.
- 오프라인 배포본: 제작 완료. 사진·스타일·기능을 포함한 HTML 한 파일입니다.
- 실제 인증·예약 저장·PG 결제·업체 지급: 미연동입니다.
- 업체·관리자 화면: 미개발입니다.
- 온라인 게시: 미완료입니다. GitHub 저장소를 연결합니다.

## 실행

원본은 `consumer-web/dist/index.html`을 Chrome 또는 Edge로 열면 됩니다. 원본 사진은 현재 외부 URL을 사용합니다. 인터넷 없이 이용하려면 오프라인 HTML을 여세요.

모든 상품·업체·일정·금액은 예시입니다. 실제 결제·예약·지급은 발생하지 않으며 예시 예약은 새로고침하면 초기화됩니다. 카카오톡 첨부파일 미리보기는 HTML 실행을 제한할 수 있습니다.

## 확정한 사업 범위

1. 소비자·업체·마인갤러리 관리자 화면이 공통 예약 데이터를 사용합니다.
2. 소비자가 PG사를 통해 결제하고 마인갤러리 수수료 20%, 업체 몫 80%를 구분합니다.
3. 각 계좌 지급 방법과 시점은 PG 계약 조건으로 확정해야 합니다.
4. 결제대행 수수료 부담과 지급 후 환불 처리 기준은 미정입니다.
5. 초기에는 개별 체험 예약에 집중합니다. 하루 일정 추천·패키지 예약은 후속 개발입니다.

## 변경 원칙

변경한 파일과 이유, 확인 결과, 남은 작업을 기록합니다. 인증정보·결제정보·고객 개인정보는 저장소에 넣지 않습니다. 원격 Git 연결 후 다른 컴퓨터에서도 같은 저장소를 사용해야 합니다.

## 개발·배포 도구

```sh
python scripts/build-offline.py
node scripts/check-consumer.cjs
node scripts/check-consumer.cjs --offline
```

Python 3와 Node.js가 필요합니다. 일반 이용자는 releases/의 HTML만 브라우저로 열면 됩니다.
